# 유지보수와 확장

이 문서는 현재 구조 debt, naming residue, observability 보강 방향을 다룬다.

## 우선순위

### P0. artifact vocabulary 정렬
- gate artifact / assembled question analysis / execution strategy를 분리한다.
- compat fallback이 실행 기본 경로로 재유입되지 않게 막는다.
- `pjt_id`와 `pjt_no` 의미 분리를 유지한다.

### P1. JOIN runtime observability
- `join_compile_selection`
- `hop2_key_strategy`
- `resolved_runtime_key_kind`
- `dual_branch_used`

### P1. 텍스트 무결성 / UTF-8
- 문서와 핵심 코드에서 mojibake를 제거한다.
- authoritative docs를 UTF-8 기준으로 유지한다.

### P2. retrieval robustness
- broad topic search
- comparison query
- complex constrained search
- follow-up query

## working rules

- planner contract를 먼저 고정하고 확장한다.
- strategy fallback과 response fallback을 구분한다.
- one file at a time으로 drift를 줄인다.
- code patch와 doc patch를 같은 변경셋으로 묶는다.
