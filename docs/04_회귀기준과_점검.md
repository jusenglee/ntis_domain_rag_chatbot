## Drift Checklist

### artifact boundary
- gate artifact와 assembled question analysis를 섞지 않는다.
- assembled question analysis와 execution strategy를 섞지 않는다.
- `request_facade.strategy_meta`와 execution summary는 다른 artifact level이다.

### invariants
- `candidate_keys.project_key` 유지
- `project_key_policy=ambiguous_or` 유지
- `join_key_mode=deferred` 유지
- `dual_branch_used` 유지
- `lookup/join + no_reranked -> normal_no_result`
- `search + no_reranked -> strict_search`

### extended runtime
- `perf_to_project_to_perf`
- `comparison`
- `series`
- `pattern_analysis`
- `multi_hop_bundle`
- `anchor_resolution`
