# SESSION PATCH TEMPLATE

> 목적: 세션 종료 시 변경 사항을 빠르게 문서 캐시에 반영하기 위한 복붙용 템플릿입니다.
> 사용 원칙: 각 섹션의 `필수 입력 항목`을 채우고, 해당 사항이 없으면 `비어 있을 때 표기 규칙`에 따라 **반드시 `변경 없음`으로 명시**합니다.

---

## 1) 오늘 변경 요약(5줄)

### 필수 입력 항목
- 변경 배경/목적 1줄
- 핵심 코드/문서 변경 3줄
- 기대 효과 또는 사용자 영향 1줄

### 비어 있을 때 표기 규칙(변경 없음)
- 변경 사항이 없으면 아래 5줄을 그대로 사용:
  1. 변경 없음
  2. 변경 없음
  3. 변경 없음
  4. 변경 없음
  5. 변경 없음

### 작성 템플릿
1. 
2. 
3. 
4. 
5.

## 2) 계약 변경 여부(있/없 + 변경 규칙)

### 필수 입력 항목
- 계약 변경 여부: `있` 또는 `없`
- 변경된 계약 문서/스키마 위치
- (변경 `있`일 때) 추가/수정/삭제된 규칙 목록
- (변경 `있`일 때) 하위 호환성 영향 및 마이그레이션 필요 여부

### 비어 있을 때 표기 규칙(변경 없음)
- 계약 변경이 없으면 다음 형식 고정:
  - 변경 여부: `없`
  - 변경 규칙: `변경 없음`
  - 하위 호환성 영향: `없음`
