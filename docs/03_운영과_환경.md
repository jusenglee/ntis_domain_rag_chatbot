# 운영과 환경

이 문서는 운영 triage, observability, 환경 검증 기준을 다룬다.

## 핵심 운영 원칙

- retrieval correctness가 answer wording보다 우선이다.
- planner invalid / contract violation은 strict fail-close다.
- response fallback과 strategy fallback을 구분한다.
- `IntentPayloadV3`와 `intent_payload_version="v3"`는 현재 운영 baseline이다.

## 주요 triage 순서

### 1. 질문 이해
확인 파일:
- `apps/api/services/request_facade.py`
- `apps/core/query_intent.py`
- `apps/core/pipeline_steps.py`

확인 포인트:
- raw query
- `NormalizedIntent`
- explicit identifier seed
- `candidate_keys.project_key`
- `project_key_policy`
- `join_resolution_policy`

### 2. planner / assembly
확인 로그:
- `PLANNER.STAGE1`
- `PLANNER.GATE`
- `PLANNER.STAGE2`
- `PLANNER.ASSEMBLE`
- `PLANNER.ASSEMBLE.ADJUSTED`

확인 포인트:
- gate join mode
- assembled join mode
- assembly adjustment kind
- assembly adjustment reason
- `join_key_mode=deferred`

### 3. execution strategy
확인 로그:
- `RAG.PLAN`
- `REQ.SUMMARY`

확인 포인트:
- `strategy_source`
- `question_analysis_mode`
- `question_analysis_relation`
- `question_analysis_join_key_mode`
- `execution_mode`
- `execution_relation`
- `execution_join_key_mode`
- `join_compile_selection`
- `resolved_runtime_key_kind`
- `dual_branch_used`
- `project_key_policy`
- `join_resolution_policy`

## REQ.SUMMARY 해석

`REQ.SUMMARY`는 planner truth와 execution truth를 구분해서 남긴다.

- `strategy_source=execution_strategy`
- `strategy_source=assembled_question_analysis_only`
- `question_analysis_*`는 assembled question analysis truth다.
- `execution_*`는 execution strategy truth다.
- `join_compile_selection`과 `resolved_runtime_key_kind`는 runtime compile truth다.

## no-result baseline

- `lookup` and `join` with `reason=no_reranked` -> `normal_no_result`
- `search` with `reason=no_reranked` remains `strict_search`
- deferred hop1 0-hit과 dual-branch 0-hit은 normal no-result로 본다.

## query_graph / 확장 capability

운영에서 자주 확인하는 값:
- `perf_to_project_to_perf`
- `pattern_analysis`
- `multi_hop_bundle`
- `comparison`
- `series`

## 환경 / 검증 명령

```powershell
python -m py_compile apps/api/main.py apps/api/app_factory.py apps/api/routes.py apps/api/runtime.py apps/api/services/request_facade.py apps/core/planner_staged.py
python -m pytest

powershell -ExecutionPolicy Bypass -File scripts/run_baseline_checks.ps1
```

## fallback 용어 규칙

- strategy fallback: 금지
- assembly legalize: 허용
- stream fallback / answer fallback / embedding fallback: 허용
- group join에서 `pjt_no -> pjt_id` 보조 fallback은 runtime metadata에 드러나야 한다.
