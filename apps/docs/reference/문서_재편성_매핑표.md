# 문서 재편성 매핑표

이 문서는 문서 재편성의 historical mapping note다. 현행 문서 구조의 source of truth는 `apps/docs/README.md`다.

이번 재편성에서는 기존 문서를 **읽기 쉬운 한국어 중심의 코어 문서 세트**로 줄였다.

흡수 대상:

변경:

- 먼저 읽을 순서 단순화
- current baseline만 남김

## 레거시 문서 처리

### `NTIS_RAG_Search_Strategy_v1_2.md`
처리 방침:
- 새 코어 문서 묶음에는 포함하지 않음
- 참고용 archive 문서로만 보관
- 현행 source of truth로 쓰지 않음

## 삭제/축약한 것

- 영어 위주 제목과 문장
- 같은 baseline을 반복하는 문장
- 지나치게 긴 aligned 표
- 현행 운영 판단에 직접 필요하지 않은 설명 문장

## 적용 권장 순서

1. 새 문서 묶음을 `docs/`에 반영
2. 기존 문서는 `docs/archive/` 또는 별도 reference 영역으로 이동
3. README 링크를 새 문서 기준으로 교체
4. 테스트 문서와 무결성 체크 대상을 새 문서명에 맞게 갱신
